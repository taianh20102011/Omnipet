OmniPets Wiki

OmniPets is a complete pet system for Paper servers. It gives your players a companion system with leveling, behaviors, skill trees, custom effects, and rich interactions.

Supported

Paper 1.21+

Java

Java 21

Features

Pet management, skills, editor, MySQL

Installation

  1. Build the plugin with Maven.
  2. Generate the JAR file.
  3. Place the file into your server's plugins/ folder.
  4. Start or restart the server.
  5. Check the generated config files and adjust them for your server.
Tip: If you are using MySQL, make sure your database config is valid before enabling the plugin.

First Run

On first startup, OmniPets will generate default files such as:

  • config.yml
  • lang/
  • skilltrees/
  • effects.yml
  • animations.yml

After generation, review the configs and test the pet system in a safe environment before using it on production servers.

Pet Behaviors

aggressive farm protect friendly aura-farming

Each pet can behave differently depending on how you want it to act. For example, a pet can protect the owner, gather resources, or stay calm and friendly.

  • Aggressive: attacks threats and engages enemies.
  • Farm: helps gather resources or farm efficiently.
  • Protect: stays near the owner and defends them.
  • Friendly: focuses on decoration and social interaction.
  • Aura-farming: enhances area effects or passive resource gain.

Skill Trees

OmniPets uses a skill tree system with many possible combinations. Skills can be customized by pet type, role, and requirements.

  • Define nodes and requirements in skill tree files.
  • Use custom effects and inherit rules for advanced progression.
  • Unlock skills through level progression and conditions.

Skill trees are stored under the plugin folder and can be managed from the editor.

Web Editor

The built-in web editor allows admins to manage content in a cleaner visual interface.

  • Skill trees editing
  • Custom effects
  • Animation configuration
  • Preview and editing for server-specific data

Open the editor in-game using /omnipets editor and configure the data from the web panel.

Configuration

Common config elements include:

  • Pet type definitions
  • Skill tree configuration
  • Behavior settings
  • Database settings
  • Animation definitions
  • Language files

Use the generated config files to tune balance, interactions, visuals, and progression.

Languages

OmniPets supports multiple languages, including examples like Vietnamese and English. You can add new language packs by creating files inside the lang/ folder.

  • lang/vi.yml
  • lang/en.yml

Troubleshooting

  • Plugin fails to start: Check Java version and database config.
  • Pet not spawning: Verify the pet type exists and is enabled.
  • Skills not working: Ensure skill tree files are valid and loaded.
  • Effects missing: Confirm effect IDs and animation names are correct.
  • Language not showing: Validate the language file name and formatting.

FAQ

Can I use it on a production server?

Yes, but always test configuration changes on a backup server first.

Does it support MySQL?

Yes. OmniPets includes MySQL-ready configuration support.

Can I create custom pets?

Yes, by configuring pet types and related data files.

Does it support PlaceholderAPI?

Yes, PlaceholderAPI integration is supported.
